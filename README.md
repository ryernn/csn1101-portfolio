# Personal Portfolio — Ryern Kanja

Personal portfolio website built progressively for **CSN 1101: Web Technologies and Internet Applications** at **KCA University** (Instructor: **Dennis Mutunga Muthui**).

## Structure & Features
- **Home (`index.html`)**: Semantic HTML5 structure, navigation bar, hero section with profile photo, about section, and contact links.
- **Projects & Skills (`projects.html`)**: Skill proficiency bars, project cards with category filtering (`All`, `Web`, `Security`), and a validated contact form.
- **Styling (`style.css`)**: Responsive external stylesheet with mobile/desktop layout support and zero inline styles.
- **Interactivity & APIs (`script.js`)**: Project category filtering, client-side contact form validation, and `Fetch API` integration with error handling.
